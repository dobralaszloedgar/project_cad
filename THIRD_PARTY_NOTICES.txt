Software dependencies
- JavaScript dependencies and their versions are recorded in package.json and
  package-lock.json. docs/dependency-licenses.json is a dated metadata
  inventory; consult the actual package license files for current terms.
- Rust dependencies and versions are recorded in rust/thermo/Cargo.toml and
  rust/thermo/Cargo.lock. Their upstream licenses apply independently.
- Fonts, icons, and vendor SDKs retain their respective upstream terms.
- Assistant packages carry separate Node.js, Zod, and Claude Agent SDK
  notices. Provider packages retain their vendor notices and terms.
  ProjectCAD-LICENSE.txt in future assistant builds contains the project's
  own reservation of rights.
