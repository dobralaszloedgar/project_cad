Project CAD release checks

The assistant build and publisher require a release policy. Keep its rule list outside the repository.

Local configuration: ~/.config/project-cad/release-policy.json
Alternative file: RELEASE_REFERENCE_POLICY_FILE
CI configuration: RELEASE_REFERENCE_POLICY, containing the policy JSON as a protected environment value.

The policy uses version 1 and a nonempty rules array. Each rule has a unique id and a nonempty terms array. Diagnostics report rule ids and file locations without quoting matched content. Scoped exceptions require both a pathPattern and an enclosingText value.

npm run assistant:check-source
Checks tracked and untracked project files, including filenames and encoded text.

npm run assistant:check-history
Checks project files plus all reachable Git objects and refs in the current checkout. Use a complete clone with every branch and tag when preparing a release.

npm run assistant:check-packages
Checks every installer and portable archive against the local checksum manifest, extracts each package, and checks its files. Run on macOS with pkgutil, tar, and 7zz available. Installers are inspected without executing them.

The Vercel Blob publisher checks project files, all ten packages, checksum sidecars, and generated release metadata before uploading. It serves only the prepared binaries and metadata, with no Git history or source archive. It verifies every public file and publishes the download manifest last. Existing files must match exactly; they are never overwritten. Only after the complete release is verified does it update the local website manifest. Deploy that manifest to activate the new download links. Dry runs inspect local files without uploading or modifying the website manifest.

The optional GitHub publisher additionally checks the current source history and public source commit. GitHub publishing requires committed source already present in the configured repository. New release tags target that exact source commit. A preexisting tag must resolve to the same commit. Run it with npm run assistant:publish:github.

After publishing, run npm run assistant:verify-downloads to verify unauthenticated download access and checksums.
