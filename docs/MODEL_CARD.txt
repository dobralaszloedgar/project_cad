PROJECT CAD MODEL CARD — 2026-10-27

AI feature: natural language to typed engineering action proposals and an
explanation grounded in the current graph and actual deterministic solver output.
Provider: official Meta Model API. Endpoint: https://api.meta.ai/v1/responses
Pinned model: muse-spark-1.3. Verified in official documentation on 2026-10-27:
https://dev.meta.ai/docs/quickstart
https://dev.meta.ai/docs/protocols/responses

The model receives the user's prompt, current graph and calculated evidence.
It never supplies authoritative numerical outputs. Proposals are Zod-validated
and checked atomically against the graph before being shown for review. A proposal
becomes stale if the project changes; stale proposals cannot be applied.
Supported actions: add equipment, connect material ports, update parameters,
remove equipment. Unknown actions and fields are rejected. There is no eval,
shell access, remote code loading or arbitrary endpoint selection.

The UI reports the actual returned model ID on successful calls. Missing
credentials disable Generate actions and leave labeled deterministic examples
available. No hardcoded response is presented as a model output.

Transport: server-only fetch; fixed endpoint; bearer token from environment;
redirects rejected; 45-second timeout; bounded request and response sizes;
10 requests per minute per server process. Same-origin loopback requests only.
This in-memory limit is appropriate for the trusted local demo, not a distributed
public service. Public AI hosting is deferred until an appropriate access and
budget-control design exists. The rest of the application can run without AI.

Verification: mocked transport contract tests and disabled-route browser tests.
A successful live Meta request has NOT been verified. Model explanations remain
untrusted prose; engineering decisions require review. No private model data,
trained weights or third-party chemical coefficients are included.

Development tools are not deployed inference dependencies. The visual concept
was generated during development and is not included in the shipped application.
